# R3 스냅핏 삽입 경사면 제안 사본

원본 R3 파일은 수정하지 않았다. Top의 네 스냅 돌기 하부에 45° 삽입 경사면을 추가한 시제품 검토안이다.

- 전면 X40.60..45.60 및 X64.60..69.60, 후면 X16.60..21.60 및 X64.60..69.60.
- 경사면: 수평 길이 1.10 mm / 높이 1.10 mm, Z8.40..9.50.
- 돌기 끝 수직 면 높이 0.20 mm, Z9.50..9.70.
- 상부 걸림면 Z9.70 및 벽 두께 방향 걸림 중첩 1.10 mm 유지.
- Bottom 형상은 동일하며, 파일을 별도 이름으로 저장했다.
- 조립 파일은 사본 형상을 내장하여 외부 파일 링크 없이 열 수 있다.

이 수정은 수직 하강 시 직각 모서리 대신 경사면이 먼저 닿도록 한다. 케이스 벽이 벌어져야 하는 상대 변위 약 1.10 mm 자체는 줄어들지 않는다. 별도 탄성 암이나 해제 구조는 추가하지 않았다. 재질 및 제작 공정이 지정되지 않아 삽입력, 응력, 반복 수명, 끝단 0.20 mm의 제작 가능성은 확정하지 않았다. 또한 기존 +Z 0.20 mm 들뜸 여유는 남아 있다. 따라서 최종 양산 승인안이 아닌 삽입 형상 검토용 사본이다.

검증 항목: Top 단일 유효 솔리드, 경사면 네 개의 존재, 기존 상부 걸림면 보존, 안착 교차 체적 0 확인 및 저장 파일 재열기. 자세한 수치는 JSON 검증 결과에 기록한다.
